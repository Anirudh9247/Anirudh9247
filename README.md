## ⭐ Featured Projects

### 🧠 [SentinelMem](#)
Cross-backend memory trust governance framework for persistent memory security in LLM agents — spanning agentic AI systems security, NLP, and trustworthy AI.

### 🛡️ [DogeshSignal](https://github.com/beyondauramarketing/Signal-V2)
AI-powered communication coach SaaS that analyzes messages for manipulation tactics. Built with Node.js/Express, React/Vite, Supabase, Razorpay, and the Gemini API — featuring server-authoritative pricing, HMAC webhook verification, and a tiered subscription model.

### 👨‍🏫 MentorMesh
City-first mentor matching platform built in a 7-day hackathon using FastAPI, PostgreSQL, React, Tailwind CSS, JWT auth, and the Claude API.

### ⚛️ [Quantum Random Number Generator](https://qrng-interactive.vercel.app)
Full-stack quantum randomness generator and statistical analysis tool using FastAPI, Qiskit-Aer, Next.js, and SQLAlchemy. Published in **IJSREM Vol. 10** (DOI: [10.55041/IJSREM59926](https://doi.org/10.55041/IJSREM59926)).
